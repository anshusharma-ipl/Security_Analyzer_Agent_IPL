What a scan costs

One real scan, measured: the agents ran on GPT-5 against the demo project (10 findings in 28 files). Every number on this page comes from that run or is simple arithmetic on it.

At a glance

$0.75cost of one scan
236,478tokens (190,198 in, 46,280 out)
81AI calls, about 19 minutes
7 of 10findings fixed; 3 left to a person

Run run-001 on 2026-10-29, project shop_demo, model GPT-5. The scan finished inside its limits: 81 of 150 calls, 28 of 50 steps, 1,143 of 2,400 seconds. Finding F007 (command injection) needed one retry because the first fix called an echo program that does not exist on Windows; the second attempt removed the subprocess call.
