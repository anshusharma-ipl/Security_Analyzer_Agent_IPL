The latest full run passed all 173 tests. 7. A live run with a real model (GPT-5, before the latest fixes)

This is the first run with a hosted model. It was made by the project owner from the console on the demo project (10 findings at the time), with all three agents on GPT-5, and its report was shared for review. It is not a benchmark: it is one run, on the version before the fixes described below.

MeasureResult
Model and endpointgpt-5 at https://api.openai.com
Tokens (real, from the API)82,902 input, 37,745 output for one scan of the 10-finding demo
Findings10: 6 SQLI, 1 CMDI, 1 PATH, 1 SECRET, 1 DEP-PIN
Result0 fixes ready, 1 rejected, 9 needs a person

Why nine needed a person, and what was done about each (all in commit 006ca90):

  • Four findings stopped on "cause unclear: no caller in the project". The console now proposes a local fix anyway, for approval, with a "cause not traced" warning (policy fix_when_cause_unclear, an owner decision recorded in AGENTS.md).
  • Two findings were rejected by the harness because the model gave a cause with no path (path was null). That was a bug, fixed with a test.
  • One fix (the multi-file SQL injection) was rejected because the Fixer could not see the second file. It now receives the other files on the traced path, and its prompt says one patch may span files. Not yet re-run with GPT-5, so whether it now succeeds is untested.
  • The secret and the dependency stay report-only by decision; they are shown as tasks for the person.
  • One finding was a real redesign (raw SQL from the client), and stayed with a person.
