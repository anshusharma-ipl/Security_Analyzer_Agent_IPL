Security Analyzer Agent

An agent that analyzes code for security issues, checked against a golden dataset of 11 cases. The Agent Opportunity Canvas is in canvas.md (read-only). Requires Python 3.11+ and the standard library only; jsonschema is the one approved package. Run python3 golden/verify_golden.py from this folder to verify the golden dataset.
