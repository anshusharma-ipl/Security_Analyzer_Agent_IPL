Next steps, in order

  1. Fix the three remaining red-team failures (a fix that passes weak tests but breaks the code, a re-check that blocks a correct fix, a safe query reported as a problem) and run them again.
  2. Score a model-backed run on all 21 cases.
  3. Have a person label every approved fix as right or wrong, to get a real false-fix rate.
  4. Record reviewer time and compare it with manual work.
  5. Set up the judge model and check it against a person on at least 20 findings.
  6. Confirm the price card, and approve the model provider and the tracing service.
  7. Name the pilot participants, repository and rules owner, then start.
