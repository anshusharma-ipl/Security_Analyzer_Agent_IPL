Limits and next steps

What is not done yet, stated plainly, and what we would do next.

What is not done yet

AreaWhere it stands
Red team8 of 10 attacks still break the system. None of the weaknesses is fixed yet.
False-fix rate27% with the built-in agents against a limit of 5%. Not measured on the live run, because nobody independently checked the approved fixes.
Model coverageOne full scan with GPT-5. Claude has run through a local bridge. The Gemini adapter has only been tested against a mock server.
Sample sizeAbout one test case per type and one live run, so the scores are a direction, not a proof.
Time savedNot measured. Reviewer time per fix, and the manual comparison, need real reviewers.
Cost baselineThe price rates need checking against a real price card, and today's engineer hours per finding are not measured.
Judge modelBuilt and tested with a stub. No judge model is set up, so there is no live result.
Tracing serviceA tracing integration sends model requests to a third-party service. It must be approved, or switched off, before any pilot.
Pilot setupParticipants, the repository and the rules owner are still to be named.

Next steps, in order

#StepWhy it comes now
1Fix the four most serious red-team failures (secrets reaching run files, patches that edit tests, false fixes, missing usage counts) and re-run.They break guardrails a pilot depends on.
2Score a model-backed run on all 21 cases.It shows whether a model closes the gaps of the built-in agents.
3Have a person label every approved fix as right or wrong.It gives a real false-fix rate on a live run.
4Record reviewer time and compare it with manual work on the same examples.It is the only way to claim time saved.
5Set up the judge model and compare it with a person on at least 20 findings.It adds a check on explanation and patch quality.
6Confirm the price card, and approve the model provider and the tracing service.They fix the cost figure and the data-handling policy.
7Name the pilot participants, repository and rules owner, then start.The pilot cannot begin without them.
