Cost Optimisation Recommendations

  1. Enable Prompt Caching — The Auditor's system prompt and rules are repeated across all 81 calls. OpenAI cached input pricing ($1.00/1M) could cut input cost by ~50%, saving ~$0.10 on this run.
  2. Use GPT-5-mini for Investigator — Investigation steps use mostly structured reasoning over known patterns. A smaller model may perform equally well at 5× lower cost.
  3. Batch Auditor re-checks — 8 individual re-check calls could be batched as one call per finding group, reducing call overhead.
  4. Reduce output token cap — Output tokens hit 77% of cap (46k/60k). For SQLI/PATH/CMDI fixes which are 3–15 line patches, a lower cap (e.g. 30k) would save cost with no quality loss.
  5. Pre-filter safe files — Files like helpers.py, greeting.py, db.py are safe. A lightweight pre-screen (AST check) before the LLM Auditor could eliminate them from AI context.
